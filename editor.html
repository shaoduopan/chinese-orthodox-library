草稿備份與匯入 · Draft Backup and Import

請定期匯出工作稿並保存在電腦或私有備份位置。瀏覽器草稿不是可靠的長期保存方式。

匯入前請先備份；若篇號相同，匯入記錄會覆蓋該篇現有的本機草稿。匯出的 JSON 是工作稿備份，不是自動發布的正式校訂本。發布到 GitHub 需要另外審核及提交。

注意：使用無痕窗口、清除網站資料或更換電腦時，本機草稿可能消失。請在提交任何重要校訂前匯出備份。
